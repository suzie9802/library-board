# 📚 책 대시보드 (library-board)

정약용도서관에서 빌린 책과 신청한 책의 **현재 상태**를 한 화면에서 보는 정적 웹앱입니다.
휴대폰·PC 모두에서 열리며, 다 읽은 책은 화면에서 바로 **읽음**으로 표시할 수 있습니다.

- 라이브: GitHub Pages에 올린 뒤 사용 (저장소 `library-board`)
- 로컬 확인: `python3 -m http.server 8000` 실행 후 <http://localhost:8000>

## 화면에 담는 것

| 영역 | 내용 |
| --- | --- |
| 상단 진척도 | 전체 등록 권수, 읽은 권수, 진척도(%) 프로그레스 바 |
| 상태 카드 | 지금 빌리는 중 · 예약·상호대차 대기 · 도서관 비치중 · 미소장 |
| 필터 | 전체 / 빌리는 중 / 예약·상호대차 / 비치중 / 읽음 / 미소장 + 제목·저자 검색 |
| 도서 카드 | 도서명·저자·출판사·연도·분류·청구기호, 정약용도서관 실제 상태 배지, 읽음 토글, 도서관 연결 버튼 |
| 도서관 연결 | ‘🏛 도서관에서 보기’(새 창, 도서명 검색 결과) · ‘📋 요청 복사’(채팅창에 붙여넣을 요청 문장을 클립보드로) |
| 하단 | 읽음 표시 JSON 내보내기·불러오기, 마지막 동기화 시각 |

## 파일

```
index.html   앱 본체 (스타일·스크립트 포함, 외부 라이브러리 없음)
books.json   도서 목록 + 정약용도서관 상태 + 마지막 동기화 시각
.nojekyll    GitHub Pages에서 Jekyll 처리 생략
```

## books.json 형식

```json
{
  "lastSyncedAt": "2026-11-18T13:24:00+09:00",
  "source": "정약용도서관 (lib.nyj.go.kr)",
  "books": [
    {
      "id": "loan-popcorn-shop",
      "list": "loan",
      "title": "(The)Popcorn Shop",
      "author": "Alice Low 글 ; Patti Hammel 그림",
      "publisher": "Scholastic",
      "year": "2021",
      "category": "영어 원서",
      "shelf": "정약용(1층)어린이자료실",
      "callNo": "원서 808.9-스875헬-3-8",
      "status": "borrowed",
      "borrowedAt": "2026-11-15",
      "dueDate": "2026-11-29"
    }
  ]
}
```

- `list`: `loan`(지금 대출) / `request`(요청한 책)
- `status`와 배지 표시

| `status` | 배지 | 추가로 쓰는 값 |
| --- | --- | --- |
| `borrowed` | 📖 빌리는 중 (반납 ~M/D) | `borrowedAt`, `dueDate` |
| `reserved` | ⏳ 예약 N순위 (반납예정 M/D) | `requestedAt`, `reserveRank`, `dueDate` |
| `ill` | 🚚 상호대차 발송 (A→B) | `requestedAt`, `illFrom`, `illTo`, `illState` |
| `available` | ✅ 정약용 비치중 (방문 대출가능) | — |
| `notheld` | ❌ 남양주 미소장 | `isbn` |

상태를 갱신할 때는 `books.json`의 항목과 `lastSyncedAt`만 고치면 화면이 그대로 따라옵니다.

## 도서관 연결 (예약으로 이어지기)

정적 페이지는 다른 사이트에 로그인하거나 예약 API를 직접 호출할 수 없습니다(CORS·보안).
그래서 카드마다 두 가지 길을 둡니다.

1. **🏛 도서관에서 보기** — `lib.nyj.go.kr`의 해당 도서명 검색 결과를 새 탭으로 엽니다. 이미 로그인한 브라우저라면 바로 예약 버튼을 누를 수 있습니다.
2. **📋 요청 복사** — 상태에 맞는 요청 문장을 클립보드에 복사합니다. 채팅창에 붙여넣으면 그대로 처리됩니다.

| 상태 | 버튼 | 복사되는 문장 |
| --- | --- | --- |
| 예약중 | 📋 예약 요청 복사 | 정약용도서관에서 『제목』 예약 신청해 줘 |
| 상호대차 | 📋 상호대차 복사 | 정약용도서관에서 『제목』 상호대차 신청해 줘 |
| 미소장 | 📋 희망도서 복사 | 정약용도서관에 『제목』 희망도서 신청할 수 있게 해 줘 |
| 비치중 | 📋 대출 문의 복사 | 정약용도서관에서 『제목』 지금 비치중인지 확인해 줘 (방문 대출) |
| 대출중 | 📋 반납 일정 복사 | 정약용도서관에서 『제목』 반납 일정 확인해 줘 |

복사가 막히는 환경(비보안 컨텍스트 등)에서는 예전 방식(`execCommand`)으로, 그것도 안 되면 문장을 직접 고를 수 있는 창을 띄웁니다.

## 정약용도서관 규정 (화면 하단에 표기)

- 자관 대출 10권 · 동시 예약 3권 · 상호대차 1인 5권(대출 권수 포함)
- 예약·상호대차 도착 알림 당일 포함 4일 내 미수령 시 예약 취소 + 다음 날부터 7일 신청 제한
- 서가 ‘비치중’ 도서는 온라인 예약 불가(방문 대출)

## 읽음 표시

- 브라우저 `localStorage` 키 `libraryBoard.v1.read` 에만 저장합니다. 서버로 보내지 않습니다.
- 기기를 바꾸거나 브라우저 데이터를 지우면 사라지므로, 하단 **내보내기**로 `reading-progress-YYYYMMDD.json` 파일을 받아 두고 새 기기에서 **불러오기**로 복원합니다.
- 아이폰 Safari: 공유 → **홈 화면에 추가**로 앱처럼 열 수 있습니다.

## 개인정보

이 저장소에는 이름·도서관 아이디·회원번호·대출번호 등 개인 식별 정보를 넣지 않습니다.
도서명·저자·출판 정보와 공개된 도서관 상태만 담습니다.
